FORWARD SIGNALS — V1

WWI communications / artillery escape-room browser prototype.

HOW TO PLAY
- Open index.html in a modern browser.
- Choose a difficulty.
- Inspect the Communication Log.
- Use Morse to contact HQ, Intelligence, and Artillery.
- Decode incoming signals.
- Use the sector map and range computer to prepare firing solutions.

NOTES FOR TESTERS
- Landscape orientation is recommended on tablets.
- The Recorded Battlefield toggle can mute/unmute battlefield ambience.
- This V1 build uses remotely hosted CC0/public-domain sound effects, so an
  internet connection is required for the recorded battlefield audio.
- Game progress is not saved between refreshes.

Please report:
- anything confusing
- anything that feels too slow or too easy
- Morse controls that misbehave
- layout problems on your device
- audio that is too loud/quiet
- any point where you did not know what to do next
