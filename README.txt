FORWARD SIGNALS — V1 OFFLINE-AUDIO BUILD

This is the same public V1 game, with the tester auto-decode button removed.

The game has been changed to load all recorded battlefield sound effects from:
    audio/

FIRST TIME SETUP ON WINDOWS
1. Double-click MAKE_OFFLINE_AUDIO.bat in the folder above UPLOAD_TO_GITHUB.
2. It downloads the exact sound files used by the current online V1.
3. When it says COMPLETE, the UPLOAD_TO_GITHUB folder is self-contained.
4. Upload the contents of UPLOAD_TO_GITHUB to the root of your GitHub repository.

After that, Forward Signals no longer needs Wikimedia/OpenGameArt while it is being played.
GitHub Pages serves the audio from your own site.

The Morse tone itself is generated by the game and does not need an audio file.
